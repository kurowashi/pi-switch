# version 1 の設定は読み込みだけ残し、pi-switch 0.3.0 で削除する

- 状態: 採用
- 日付: 2026-10-16
- 対象: 設定ファイルの version 1 形式（`disabled` / `enabled` のリスト）の読み込み

## 背景

pi-switch 0.1.x は version 1 の形式で設定を書きます。[0007](0007-tri-state-values-and-project-precedence.md) で値の形式と解決規則を変えたため、利用者の既存ファイルをそのままでは解釈できません。

## 決定

- version 1 のファイル（`version` 省略を含む）は読み込みます。読み込んだ値は、同じ意味の version 2 の値に変換します。
- 変換のコードは `src/legacy-v1.ts` に分離し、`src/config.ts` からだけ呼びます。
- 次にそのファイルを書くと、version 2 で書き直します。
- pi-switch 0.3.0 で、`src/legacy-v1.ts` とそのテスト（`test/unit/legacy-v1.test.ts`）、および version 1 の読み込み分岐を削除します。削除の時点で version 1 のファイルは読み込まれず、設定は空として扱われ、警告が表示されます。

## 理由

- 読み込みを残すと、既存の利用者の設定が変更後も同じ効果を持ちます。手作業の移行を強いずに済みます。
- 変換は同じ対象の値を同じ効果に写すだけです。Project が Global より優先される点は、旧 4 段の逐次適用と結果が一致します（テストで確認）。
- 削除期限を決めておくことで、変換のコードが恒久的な 2 つ目の解決規則として残ることを防ぎます。

## 却下した代替

| 代替 | 却下理由 |
|---|---|
| 読み込みを即時に削除する | 0.1.x の設定が無視され、利用者の無効化がすべて消える |
| 読み込みを恒久的に残す | 解決規則が 2 つ残り、0007 の目的（規則の一本化）に反する |
| 変換コマンドを提供する | 利用者が実行を忘れると、無効化が消える。自動で書き換えるなら読み込み時の変換と同じ |
