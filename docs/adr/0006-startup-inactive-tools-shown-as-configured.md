# 一覧の状態は設定の状態のまま表示し、起動時に無効なツールは README に明記する

- 状態: 廃止（[0007](0007-tri-state-values-and-project-precedence.md) に置き換え。未設定のツールは Pi の既定を表示する）
- 日付: 2026-10-13
- 対象: `/switch` の Tools 行の表示と、起動時に Pi が有効にしていないツールの扱い

## 背景

Pi は `read` / `bash` / `edit` / `write` 以外のツールを既定では有効にしません（`dist/core/settings-manager.js` の `DEFAULT_TOOL_NAMES`）。
pi-switch の一覧は「無効化されていない」を ● で表示するため、起動直後の `grep` は ● と表示されます。
Space を 1 回押すと ○ になりますが、モデルのツール一覧には変化がありません。もう 1 回押すと ● になり、有効になります。

## 決定

- 一覧の ● / ○ は、全層を適用した設定の状態を表します。モデルに届いているかどうかは表しません。
- 起動時に Pi が有効にしていないツールの扱いは README に明記します。
- 一覧の表示を有効集合から導く変更は行いません。

## 理由

- 有効集合から表示を導くと、表示が設定と有効集合の二重の正になります。`enabled` の意味が「無効化の打ち消し」から「強制的に有効」へ変わり、解決規則と設定形式を変えることになります。
- 表示の規則を明記する変更は、設定形式・解決規則・適用規則を変えません。
- 2 回押す挙動は、ADR 0005 の「起動時に有効でないツールは `/switch` で明示的に有効化したときだけ有効になる」を満たします。

## 帰結

- 利用者は README の「起動直後の ●」を読めば、表示と効果の差を理解できます。
- 表示と効果を一致させたい要望が出た場合、この ADR を置き換える新しい ADR を作り、設定形式の変更を伴うことを明記します。
